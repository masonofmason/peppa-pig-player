==============================================
  Peppa Pig Player 설치 및 실행 방법
==============================================

Peppa Pig 공식 영어 채널 영상을 찾아 보고, 본 영상 / 보고 있는 영상 / 안 본 영상으로
나누어 확인할 수 있는 앱입니다. 인터넷 연결이 필요합니다.


[1] 설치
----------------------------------------------
받은 zip 파일을 마우스 오른쪽 버튼 → "압축 풀기"로 원하는 폴더에 풉니다.
(zip 안에서 바로 실행하지 말고 꼭 압축을 푼 뒤 실행하세요)

따로 설치할 프로그램은 없습니다.


[2] 실행
----------------------------------------------
■ Windows
  start.bat 파일을 더블클릭합니다.
  → 검은 창이 뜨고 잠시 후 브라우저에 앱이 열립니다.
  → 앱을 쓰는 동안 검은 창을 닫지 마세요. 창을 닫으면 앱이 종료됩니다.

  "Windows의 PC 보호" 파란 창이 뜨면:
    "추가 정보" → "실행"을 누르세요.

■ Mac
  터미널을 열고 압축을 푼 폴더에서 아래 명령을 실행합니다.
    sh start.command
  (Node.js 또는 Python 3가 필요합니다. 없으면 https://nodejs.org 에서 설치하세요)

브라우저가 자동으로 열리지 않으면 주소창에 http://localhost:5173 을 입력하세요.


[3] YouTube API 키 등록 (처음 한 번)
----------------------------------------------
앱에서 "YouTube API 키가 필요합니다"라는 안내가 보이면 키를 등록해야 합니다.
(이미 키가 들어 있는 상태로 받았다면 이 단계는 건너뛰세요)

  1. https://console.cloud.google.com 에 Google 계정으로 로그인합니다.
  2. 새 프로젝트를 만듭니다.
  3. https://console.cloud.google.com/apis/library/youtube.googleapis.com
     에서 "YouTube Data API v3"를 "사용" 으로 설정합니다.
  4. https://console.cloud.google.com/apis/credentials
     에서 "사용자 인증 정보 만들기" → "API 키"를 누릅니다.
  5. 만들어진 키(AIza로 시작)를 복사해 앱의 "API 키 등록하기"에 붙여넣고 저장합니다.

무료입니다. 처음 실행할 때 공식 채널의 영상 목록을 한 번 받아 오며(잠시 걸릴 수 있음),
그 뒤로는 검색을 몇 번 하든 API 사용량이 거의 들지 않습니다.


[4] 알아두세요
----------------------------------------------
- 시청 기록과 API 키는 이 컴퓨터의 브라우저 안에만 저장됩니다.
  다른 브라우저로 열면 기록이 따로 관리됩니다.
- 항상 같은 브라우저, 같은 주소(http://localhost:5173)로 여세요.
  주소의 숫자(포트)가 바뀌면 이전 시청 기록이 보이지 않습니다.
  (다른 프로그램이 5173번을 쓰고 있으면 5174번 등으로 열릴 수 있습니다)
- 일부 영상은 업로더 설정 때문에 앱 안에서 재생되지 않을 수 있습니다.
