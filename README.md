# Peppa Pig Player 🐷

Peppa Pig 공식 영어 채널(Peppa Pig - Official Channel)의 영상을 앱 안에서 보고, 시청 상태별로 나눠 볼 수 있는 웹앱입니다.

- **전체**: 공식 채널 영상 (검색어·날짜 조건에 맞는 것)
- **아직 안 본 영상**: 그중 재생한 적 없는 영상
- **보고 있는 영상**: 재생했지만 끝까지 보지 않은 영상 (다시 열면 이어서 재생)
- **본 영상**: 끝까지 본 영상 (95% 이상 시청 또는 남은 시간 10초 이하)

### 제목 검색 · 정렬

검색창에 입력하는 즉시 제목으로 걸러집니다(대소문자 무관, 여러 단어는 모두 포함). 업로드 날짜 기준 최신순/오래된순으로 정렬할 수 있습니다.

**한글로도 검색됩니다.**
- **번역 방식:** "진흙탕", "조지랑 공룡", "아빠 돼지"처럼 입력하면 단어장(`public/ko-dictionary.js`)으로 영어로 바꿔 영어 제목에서 찾습니다.
- **입력 형태:** 조사, 띄어쓰기, 한영 혼합 입력도 알아듣습니다. 검색창 아래에 어떻게 바꿨는지 표시됩니다.
- **모르는 단어:** 단어장에 없는 단어는 화면에 알려 줍니다.
- **단어 추가:** `ko-dictionary.js`에 `'한글': ['english'],` 한 줄을 넣으면 됩니다.

### 음성 검색 🎤

검색창 옆 🎤 버튼을 누르고 말하면 바로 검색합니다.

- **언어 전환:** 🎤 옆 **[한 | EN]** 버튼으로 인식 언어를 바꿀 수 있습니다. 영어는 페파피그 발음에 맞춰 영국 영어(en-GB)로 듣고, 마지막 선택을 기억합니다.
  - **한:** 한국어로 인식 → 한글 단어장 검색. 영어로 말해서 "버스데이"처럼 받아 적혀도 단어장이 알아듣습니다.
  - **EN:** 영어로 인식 → "show me muddy puddles"처럼 말해도 show, me 같은 말은 무시하고 찾습니다.

- **동작 환경:** PC·안드로이드의 Chrome·Edge, 아이폰 Safari에서 동작합니다. 처음 한 번 마이크 권한을 허용해야 합니다.
- **미지원 브라우저:** 음성 인식을 지원하지 않는 브라우저(대부분의 TV 브라우저, Firefox 등)에서는 버튼이 보이지 않습니다.
- **TV에서 음성 입력하기:** 휴대폰 리모컨 앱(SmartThings, LG ThinQ, Google TV)의 키보드 🎤나 리모컨 마이크로 검색창에 입력하세요.

### 쇼츠 구분

날짜 필터 줄의 **[전체 영상 / 일반 영상만 / 쇼츠만]**으로 고를 수 있습니다. 마지막 선택을 기억하고 모든 탭에 적용됩니다. 쇼츠 카드에는 빨간 "쇼츠" 배지가 붙습니다.

- **판단 기준:** YouTube API는 쇼츠 여부를 알려주지 않으므로, 제목이나 설명에 `#shorts`가 있거나 길이가 60초 이하면 쇼츠로 봅니다.
- **오분류 가능성:** 공식 채널은 쇼츠에 거의 항상 `#Shorts`를 붙입니다. 다만 표시 없는 60초 초과 쇼츠는 일반 영상으로 분류될 수 있습니다.

### 업로드 날짜 필터

탭 아래의 **업로드 날짜**에서 년 → 월 → 일 → 시 순서로 범위를 좁힐 수 있습니다. 예를 들어 "2024년 3월"만 고르면 그 달 전체, 시간까지 고르면 그 1시간 동안 업로드된 영상만 보여줍니다. 시간은 내 컴퓨터의 시간대(한국이면 KST) 기준입니다. 이 필터는 모든 탭에 함께 적용되며, 각 카드에 업로드 일시가 표시됩니다.

## 휴대폰에서 사용하기

**https://masonofmason.github.io/peppa-pig-player/** 에 올라가 있습니다. 휴대폰 브라우저로 열고 ⚙ 설정에 API 키를 한 번 입력하면 됩니다.

- **아이폰(Safari):** 공유 버튼 → "홈 화면에 추가"
- **안드로이드(Chrome):** ⋮ 메뉴 → "홈 화면에 추가" 또는 "앱 설치"

홈 화면 아이콘으로 열면 앱처럼 전체 화면으로 실행됩니다. 시청 기록은 기기마다 따로 저장됩니다. 아이폰은 Safari에서 연 것과 홈 화면 아이콘으로 연 것도 기록이 서로 다를 수 있습니다.

`main` 브랜치에 푸시하면 GitHub Actions(`.github/workflows/pages.yml`)가 `public/` 폴더를 자동으로 다시 배포합니다.

## 실행 (PC)

```bash
npm start
```

브라우저에서 http://localhost:5173 을 엽니다. (포트 변경: `PORT=8080 npm start`)
설치할 의존성은 없습니다. Node.js 18 이상만 있으면 됩니다.

## 다른 PC에 배포하기

```bash
npm run package
```

`dist/peppa-pig-player.zip`이 만들어집니다. 받는 사람은 압축을 풀고 `start.bat`(Windows)을 더블클릭하면 됩니다. 자세한 안내는 zip에 들어 있는 `INSTALL.txt`에 있습니다.

- **Node.js가 있는 PC:** Node.js로 실행합니다.
- **Node.js가 없는 PC:** Windows 기본 PowerShell(`server.ps1`)로 실행하므로 따로 설치할 것이 없습니다.
- **Mac:** `sh start.command`로 실행합니다. Node.js 또는 Python 3가 필요합니다.
- **API 키 미리 넣기:** `public/config.js`의 `apiKey`에 키를 넣고 패키징하면 받는 사람은 키를 입력하지 않아도 됩니다. 모든 사용자가 그 키의 사용량을 나눠 쓰지만, 한 사람이 하루에 쓰는 양이 적어서 여러 명이 써도 충분합니다. 다만 파일을 받은 사람은 누구나 키를 볼 수 있습니다.

## YouTube API 키

처음 실행하면 YouTube Data API v3 키를 입력하라는 안내가 나옵니다.

1. [Google Cloud Console](https://console.cloud.google.com/apis/library/youtube.googleapis.com)에서 YouTube Data API v3를 사용 설정합니다.
2. [사용자 인증 정보](https://console.cloud.google.com/apis/credentials)에서 API 키를 만듭니다.
3. 앱의 ⚙ 설정에 붙여넣습니다.

### API 사용량

무료 할당량은 하루 10,000 유닛입니다. 이 앱은 사용량이 큰 YouTube 검색 API(호출당 100 유닛)를 쓰지 않고, 공식 채널의 업로드 목록(50개당 약 2 유닛)을 받아 브라우저에 보관합니다.

- **처음 실행:** 채널 전체 목록을 받습니다. 영상 수에 따라 수백 유닛이 들고, 중간에 끊기면 다음에 이어받습니다.
- **그 뒤:** 앱을 열 때 1시간 넘게 지났으면 새 영상만 확인합니다. 보통 2 유닛이 듭니다. "새 영상 확인" 버튼으로 직접 확인할 수도 있습니다.
- **검색·필터·정렬:** 브라우저 안에서 처리하므로 사용량이 들지 않습니다.

## 데이터 저장

API 키, 시청 기록, 채널 영상 목록은 브라우저 localStorage에만 저장됩니다. 다른 브라우저나 기기와는 공유되지 않습니다.
